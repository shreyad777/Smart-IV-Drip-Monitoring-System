# Project Roadmap

## Completed

- [x] ESP32-based monitoring system
- [x] Load cell-based IV bag weight measurement
- [x] HX711 integration
- [x] 20×4 I2C LCD status display
- [x] Low-fluid detection
- [x] Audible buzzer alert
- [x] Basic project documentation
- [x] GitHub repository setup

## Planned Improvements

- [ ] Perform and document load-cell calibration
- [ ] Add adjustable fluid-level threshold
- [ ] Improve measurement stability and filtering
- [ ] Add battery-powered operation
- [ ] Add data logging
- [ ] Support multiple IV bags
- [ ] Add optional remote monitoring
- [ ] Develop a mobile/web dashboard
- [ ] Conduct extended prototype testing
- [ ] Improve enclosure and physical design

## Long-Term Vision

The project can be developed into a more reliable healthcare-assistance prototype capable of monitoring multiple IV fluid bags and providing timely notifications while maintaining a simple and non-invasive monitoring approach.
